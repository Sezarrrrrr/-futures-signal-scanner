# Futures Signal Scanner Web v2

Binance USDⓈ-M Futures market data kullanan mobil web prototipi.

- 5m + 15m + 1h
- EMA 20/50/200
- RSI 14, MACD, ATR
- Hacim oranı
- Funding rate
- Open interest
- Global long/short account ratio
- Çoklu zaman dilimi sinyal skoru
- LONG / SHORT / NÖTR
- Giriş, SL, TP1, TP2, TP3
- Volatiliteye göre kaldıraç önerisi
- API key ve gerçek emir yok

Skor başarı olasılığı veya kâr garantisi değildir. Gerçek para ile kullanmadan önce backtest ve paper trading yapılmalıdır.
